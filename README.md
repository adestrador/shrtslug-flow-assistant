# Shrtslug Flow Assistant

A lightweight open-source userscript for repetitive Shrtslug flow pages.

---

## English

### What it does

* Automates repetitive steps on supported Shrtslug flow pages.
* Waits for website timers rather than skipping them.
* Detects available buttons and continues automatically when possible.
* Keeps CAPTCHA and human-verification tasks manual.
* Shows an on-page status indicator in Brazilian Portuguese.

### Supported domains

* `shrtslug.biz`
* `digiztechno.com`
* `tournguide.com`
* `yrtourguide.com`
* `techmize.net`
* `technons.com`
* `biovetro.net`
* `dailyjobposting.xyz`
* `financefernly.com`

The script also applies to subdomains of the domains listed above.

### Privacy and limitations

This script contains no analytics, remote code loading, or data collection. Website layouts and flows may change at any time.

The script does not solve CAPTCHAs or other human-verification challenges. Use it only where permitted and in accordance with the applicable website terms.

### Project status

This is a stable public release with no planned maintenance schedule.

Community forks, bug reports, and pull requests are welcome. Responses, merges, and future releases are not guaranteed.

## Português (Brasil)

### O que ele faz

* Automatiza etapas repetitivas das páginas compatíveis com o fluxo Shrtslug.
* Aguarda os temporizadores do próprio site, sem tentar pulá-los.
* Detecta botões liberados pela página e continua automaticamente quando possível.
* Mantém CAPTCHA e verificações humanas para serem resolvidos manualmente.
* Exibe um indicador de status na página, em português brasileiro.

### Domínios compatíveis

* `shrtslug.biz`
* `digiztechno.com`
* `tournguide.com`
* `yrtourguide.com`
* `techmize.net`
* `technons.com`
* `biovetro.net`
* `dailyjobposting.xyz`
* `financefernly.com`

O script também se aplica aos subdomínios dos endereços listados.

### Privacidade e limitações

Este script não contém analytics, carregamento de código remoto nem coleta de dados. O layout e o fluxo dos sites podem mudar a qualquer momento.

O script não resolve CAPTCHA nem outras verificações humanas. Use-o apenas onde isso for permitido e de acordo com os termos aplicáveis do site.
